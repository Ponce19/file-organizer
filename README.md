# File Organizer
This program is mainly focused on organizing file whit the extensionsm .docx .pptx .xmlx and .pdf in container folders whit their respective file names 

## Characteristics

*Folder Select
*Automatic Organization of extensions
*Aotomatic creation of subfolders
*Simple graphical interface
*Record of movements made

## Technologies

-Python 3
-Tkinter
-Pathlib
-Shutil

## Instalation

--First--

git clone https://github.com/TU-USUARIO/file-organizer.git

--Second--

Enter the project:

cd file-organizer

--Third--

Run:

python main.py
